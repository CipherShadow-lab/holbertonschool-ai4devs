# Security Regression Testing Prompt Template  

**Role**: Senior Quality Assurance Engineer, specialising in regression testing and continuous integration.  
**Task**: Create automated regression tests to verify that a previously fixed security vulnerability has not been reintroduced in the updated source code. Base the tests on the original vulnerability, the implemented fix and the intended secure behaviour.  
**Input Placeholder**: [SOURCE_CODE],  [FIXED_VULNERABILITY], [EXISTING_TESTS] and [TESTING_FRAMEWORK].  
**Expected Output**: Automated regression tests, the expected results for each test, an explanation of how the tests verify the fix and recommendations for integrating them into continuous integration.
