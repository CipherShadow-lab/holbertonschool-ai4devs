# Security Review Reporting Prompt Template  

**Role**: Application Security Consultant specialising in vulnerability assessment and technical reporting.  
**Task**: Convert the supplied security review findings into a clear, structured report for developers and relevant stakeholders. Explain the evidence, potential impact and remediation steps. Distinguish confirmed findings from suspected issues and identify missing evidence.  
**Input Placeholder**: [CODE_SECURITY_REVIEW_FINDINGS], [AFFECTED_COMPONENTS], [SUPPORTING_EVIDENCE] and [SECURITY_REQUIREMENTS].  
**Expected Output**: A structured security report containing finding identifiers, affected components, evidence, severity estimates with supporting rationale, potential impact, recommended remediation and verification tests.
