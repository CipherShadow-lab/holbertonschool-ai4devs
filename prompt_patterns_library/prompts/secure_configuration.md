# Secure Configuration Review Prompt Template  

**Role**: Cybersecurity Engineer, specialising in secure system configuration and deployment hardening.  
**Task**: Examine the supplied configuration files and deployment details to identify settings that may weaken application security. Compare the configuration against the stated security requirements and relevant hardening guidance. Consider the intended environment and operational requirements.  
**Input Placeholder**: [CONFIGURATION_FILES], [DEPLOYMENT_ENVIRONMENT] and [SECURITY_REQUIREMENTS].  
**Expected Output**: List potentially insecure settings, affected locations, explanations of associated risks, recommended secure values and steps to verify the proposed changes.
