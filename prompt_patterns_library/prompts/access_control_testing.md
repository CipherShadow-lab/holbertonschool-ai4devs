# Access Control Testing Prompt Template  

**Role**: Act as a Security Test Engineer specialising in role-based access control and API security.  
**Task**: Design automated tests to verify that users can access resources and perform actions only when permitted by their roles, permissions and resource ownership. Include authorised and unauthorised access scenarios.  
**Input Placeholder**: [API_ENDPOINTS], [USER_ROLES], [RESOURCE_OWNERSHIP_RULES] and [TESTING_FRAMEWORK].  
**Expected Output**: Automated test cases covering permitted and denied operations, different user roles, resource ownership, unauthenticated requests and expected HTTP status codes or application responses.
