# Negative Input Validation Testing Prompt Template  

**Role**: Act as a Software Test Engineer, specialising in security testing and automated test design.  
**Task**: Design automated negative tests for the supplied function or endpoint. Cover malformed input, unexpected data types, missing values, boundary conditions and security-relevant invalid input. Verify that the application handles failures safely and consistently.  
**Input Placeholder**: [FUNCTION_OR_ENDPOINT], [ACCEPTED_INPUT_RULES], [TESTING_FRAMEWORK] and [EXPECTED_ERROR_BEHAVIOUR].  
**Expected Output**: Automated test cases containing test names, input data, setup requirements where necessary, expected results and assertions for validation failures and error handling.
