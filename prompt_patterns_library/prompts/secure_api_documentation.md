# Secure API Documentation Prompt Template  

**Role**: Act as a Technical Writer specialising in API documentation and application security.  
**Task**: Produce developer-facing API documentation that explains how to interact with the supplied API securely. Document authentication, authorisation, request validatio, relevant security requirements and appropriate error handling. Do not invent undocumented API behaviour.  
**Input Placeholder**: [API_SPECIFICATION], [AUTHENTICATION_METHODS], [ACCESS_CONTROL_RULES] and [REQUEST_VALIDATION_REQUIREMENTS]. 
**Expected Output**: Structured API documentation containing endpoint descriptions, authentication requirements, permission rules, reques and response examples, expected error responses and secure usage guidance.
